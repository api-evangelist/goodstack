# Goodstack

> Goodstack (formerly Percent) is an impact platform whose REST API lets businesses build charitable giving, nonprofit verification, and fund disbursement into their products. It handles vetting, validation, and timely disbursement of donations to verified nonprofit and educational organisations across many countries and currencies.

Base URL: https://api.goodstack.io/v1 (sandbox: https://sandbox-api.goodstack.io)
Auth: API key in the Authorization header (publishable `pk_`, secret `sk_`).
Idempotency: `Idempotency-Key` header on POST endpoints (21-day retention).
Pagination: `pageSize` query param (default 25, max 100); cursor and offset links.

## APIs

- [Goodstack Services API reference](https://docs.goodstack.io/docs/api/goodstack-services): 62 operations across donations, organisations, verifications, validation, subscriptions, categories, and webhooks.
